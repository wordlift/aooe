AOOE — Agent-Oriented Ontology Engineering vocabulary

Namespace https://w3id.org/aooe# · version 0.7.0 · published by WordLift.

Terms the AOOE methodology uses to annotate import manifests, Behavioral Concept Specifications and adoption levels (Legend ⊂ Map ⊂ Rulebook). A methodology vocabulary, not a domain vocabulary: it never appears in a public data projection.

Adoption levels (individuals)

TermLabelDefinition
aooe:LegendLegendThe vocabulary reference: which external vocabularies are reused, at which verified versions, under which prefixes, and how instance identifiers are minted. Done when every import is pinned and verified, every prefix binds to one IRI, pins live only in the import manifest, and the identity policy is written.
aooe:MapMapThe data model: classes, properties, application profiles, qualified relations and locally added property characteristics. Done when Legend is done, every term carries a label and a definition, reused external terms are wired, no external property carries a local domain or range, the module is reasoner-consistent, and at least one positive example uses the term with only declared terms.
aooe:RulebookRulebookValidation and behavior: SHACL shapes, negative examples, Behavioral Concept Specifications, policy envelopes, gates, eval items and reward specs. Done when Map is done and the full definition of done holds: shapes target the class, positives conform, negatives fail independently, the non-vacuity sentinel passes, the BCS has eleven sections, the envelope is signed, and eval and reward execute.
